# Lib24 ALL reduced model: robustness to \(d_{mA}\)

## Overview

This directory repeats the Lib24 all-construct reduced-model estimation while fixing the non-ribosomal mRNA degradation rate, \(d_{mA}\), at several values:

```text
0.15, 0.17, 0.20, 0.22, and 0.25 min^-1
```

The RBS inverse scaling parameter is fixed at:

```text
rho^0 = 0.02
```

The workflow tests how the selected \(d_{mA}\) value changes the objective function, estimated promoter rates, RBS intrinsic initiation capacities, and effective pGreen copy number.

The case \(d_{mA}=0.20\ \mathrm{min}^{-1}\) is used as the reference in the robustness analysis.

## Distribution policy

The public distribution includes:

```text
Estimated_results/
```

with the BADS optimization outputs for each fixed \(d_{mA}\).

The compiled files

```text
Results_Tensor_Lib24_ALL_reduced_model_Wells_dma_<tag>.mat
```

are not distributed because each file is large. They can be regenerated from the supplied optimization outputs by running:

```matlab
Generate_Results_Lib24_ALL_reduced_model_set_dma
```

## Workflow

### 1. Parameter estimation

Run:

```matlab
Estimate_Lib24_ALL_reduced_model_set_dma
```

The script performs repeated BADS optimizations for all 24 Lib24 constructs.

Estimated parameters:

- promoter transcription rates for J23106, J23102, and J23101;
- RBS intrinsic initiation capacities for B0030, B0032, J61100, and J61101;
- the pGreen/pSC101 effective copy-number multiplier.

Fixed quantities:

- \(N_{\mathrm{pSC101}}=5\);
- \(\rho^0=0.02\);
- one selected \(d_{mA}\) per optimization batch.

Generated files:

```text
Estimated_results/
    Results_BADS_Lib24_ALL_reduced_Wells_dma_15.mat
    Results_BADS_Lib24_ALL_reduced_Wells_dma_17.mat
    Results_BADS_Lib24_ALL_reduced_Wells_dma_2.mat
    Results_BADS_Lib24_ALL_reduced_Wells_dma_22.mat
    Results_BADS_Lib24_ALL_reduced_Wells_dma_25.mat
```

The exact tag is generated with MATLAB's `num2str` and `extractAfter` convention.

### 2. Result-tensor generation

Run:

```matlab
Generate_Results_Lib24_ALL_reduced_model_set_dma
```

For each \(d_{mA}\), the script:

- loads the corresponding BADS runs;
- computes parameter means and standard deviations;
- attaches the estimates to the processed Lib24 experimental tensor;
- computes global, instance-level, and well-level sensitivities;
- generates host-aware synthesis predictions over a growth-rate grid;
- propagates parameter uncertainty through Monte Carlo sampling;
- saves a complete result tensor.

Generated files follow:

```text
Results_Tensor_Lib24_ALL_reduced_model_Wells_dma_<tag>.mat
```

These files are regeneration products and are intentionally omitted from the distributed archive.

### 3. Visualize one \(d_{mA}\) case

Run:

```matlab
Show_Results_Lib24_ALL_reduced_model_set_dma
```

Select the desired value through:

```matlab
model_c.dm_c = set_dma(...);
```

The script calls:

```matlab
Plot_Results_Lib_reduced_model(...)
```

using the backward-compatible seven-argument interface. The current plotting function therefore remains compatible with this workflow.

### 4. Compare all \(d_{mA}\) cases

Run:

```matlab
Show_Compared_Results_Lib24_ALL_reduced_model_set_dma
```

This script compares objective values with the estimated plasmid, promoter, and RBS parameters across the five fixed degradation rates.

### 5. Robustness analysis

Run:

```matlab
Show_Robustness_dma_Lib24_ALL_reduced_model
```

The script uses \(d_{mA}=0.20\ \mathrm{min}^{-1}\) as the reference and generates:

```text
Figures/
    Fig_dmA_CostAndSensitivity.png/.svg
    Fig_dmA_IndividualViolins_ByParameter.png/.svg
    Fig_dmA_CollapsedViolins_Grouped_Balanced_AbsoluteLog_OverlayRef.png/.svg

Tables/
    Table_dmA_cost_summary.csv
    Table_dmA_loglog_sensitivity.csv
    Table_dmA_collapsed_grouped_balanced_summary.csv
```

The collapsed distributions use the same number of optimization runs per \(d_{mA}\) value to avoid over-representing cases with more runs.

## Turnover-to-resource ratio analysis

`Analyze_dmA_ratio_all_TUs.m` evaluates:

```text
d_mA*(rho^0 + f_s(mu))/(kappa^0*varphi(mu))
```

for Lib24 and Lib6 over the stored prediction grid and at the experimental growth rates of each construct.

This script requires both:

```text
Results_Tensor_Lib24_ALL_reduced_model_Wells_dma_<tag>.mat
Results_Tensor_Lib6_ALL_reduced_model_Wells_dma_<tag>.mat
```

The Lib6 tensor is generated by the corresponding Lib6 \(d_{mA}\) workflow and is not produced in this directory.

Outputs are written to:

```text
Analysis_results/
Figures/
```

## Objective function

`J5w_LogPI_Lib24_ALL_reduced.m` is shared across all \(d_{mA}\) cases. The selected degradation rate enters through:

```matlab
model_c.dm_c
```

The objective compares predicted and experimental synthesis rates in base-10 logarithmic space using a weighted pseudo-Huber loss.

## Required shared functions and data

The workflow requires:

```text
Generate_HEM/HEM_Surrogate/HEM_Surrogate.mat
Experimental_Data/ExpData_Tensor_lib30_micro.mat
Experimental_Data/ExpData_Tensor_lib24_micro.mat
Scripts_base/Get_synthesis_predictions.m
Scripts_base/Get_synthesis_predictions_lite.m
Scripts_base/Plot_Results_Lib_reduced_model.m
```

It also requires BADS and the truncated multivariate-normal sampler used by the result-generation workflow.

## MATLAB requirements

- MATLAB with local functions in scripts;
- BADS;
- Parallel Computing Toolbox for `parfor`, unless replaced with `for`;
- Statistics and Machine Learning Toolbox for `fitdist`, `ksdensity`, and `prctile`;
- `exportgraphics`;
- the `rmvnrnd` implementation available in the SynTwin distribution.

GNU Octave compatibility has not been tested.
