# Lib30 ALL reduced model: robustness to \(d_{mA}\)

## Overview

This directory repeats the all-construct Lib30 reduced-model estimation while
fixing the non-ribosomal mRNA degradation rate at:

```text
0.15, 0.17, 0.20, 0.22, and 0.25 min^-1
```

The RBS inverse scaling parameter is fixed at:

```text
rho^0 = 0.02
```

Lib30 contains 30 constructs formed from two plasmid backbones, three promoters,
and five RBS variants, including B0034. The case \(d_{mA}=0.20\ \mathrm{min}^{-1}\)
is the reference in the robustness analyses.

## Distribution policy

The public distribution includes only:

```text
Estimated_results/
```

with the BADS optimization outputs for each fixed \(d_{mA}\).

The compiled files

```text
Results_Tensor_Lib30_ALL_reduced_model_Wells_dma_<tag>.mat
```

are not distributed because of their size. They can be regenerated by running:

```matlab
Generate_Results_Lib30_ALL_reduced_model_set_dma
```

## Workflow

### Parameter estimation

```matlab
Estimate_Lib30_ALL_reduced_model_set_dma
```

Estimated parameters:

- promoter transcription rates for J23106, J23102, and J23101;
- RBS intrinsic initiation capacities for B0030, B0032, B0034, J61100, and J61101;
- the pGreen/pSC101 effective copy-number multiplier.

Generated files:

```text
Estimated_results/
    Results_BADS_Lib30_ALL_reduced_Wells_dma_<tag>.mat
```

### Result-tensor generation

```matlab
Generate_Results_Lib30_ALL_reduced_model_set_dma
```

For each \(d_{mA}\), the script compiles parameter statistics, experimental
data, local sensitivities, synthesis predictions, and Monte Carlo uncertainty
results into:

```text
Results_Tensor_Lib30_ALL_reduced_model_Wells_dma_<tag>.mat
```

These files are regeneration products and are intentionally omitted from the
distributed archive.

### Robustness analysis

```matlab
Show_Robustness_dma_Lib30_ALL_reduced_model
```

The script compares all nine inferred quantities:

```text
J23106, J23102, J23101
B0030, B0032, B0034, J61100, J61101
pGreen
```

Outputs are written to:

```text
Figures/
Tables/
```

### Turnover-to-resource ratio analysis

```matlab
Analyze_dmA_ratio_Lib30_ALL_TUs
```

The script evaluates:

```text
d_mA*(rho^0 + f_s(mu))/(kappa^0*varphi(mu))
```

for all 30 constructs and all five \(d_{mA}\) values. It exports summaries by
construct, RBS, and reference-regime classification to:

```text
Analysis_results/
Figures/
```

## Objective function

All parameter estimations in this directory use:

```text
J5w_LogPI_Lib30_ALL_reduced.m
```

The selected degradation rate enters through `model_c.dm_c`. The objective
compares predicted and experimental synthesis rates in base-10 logarithmic
space using a weighted pseudo-Huber loss.

## Requirements

- MATLAB with local functions in scripts;
- BADS;
- Parallel Computing Toolbox for `parfor`, unless replaced with `for`;
- Statistics and Machine Learning Toolbox;
- `exportgraphics`;
- the `rmvnrnd` implementation distributed with SynTwin;
- the HEM surrogate and Lib30 processed experimental tensor.

GNU Octave compatibility has not been tested.
